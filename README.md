# Task Management API

A lightweight, in-memory REST API built with FastAPI to manage a to-do list.

## Development Status
* CRUD endpoints completed (GET, POST, PUT, DELETE).
* Swagger UI configured.

## Swagger Documentation
Interactive API docs are automatically generated and can be accessed locally at:
`http://localhost:8000/docs`
